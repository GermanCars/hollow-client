The first polished version of Hollow Client, for Minecraft 26.3 on Fabric.

**Install:** put `hollow-client-26.3-0.1.0.jar` and [Fabric API](https://modrinth.com/mod/fabric-api) in your `mods` folder. Java 25 is needed. Add Litematica and MaLiLib to use Printer and AutoBuild.

- 158 modules and 36 HUD elements
- Litematica printer that places blocks the right way round
- One-window menu with search, themes, friends and profiles
- Ice cavern start menu and frosted glass in the whole game

<kbd>Right Shift</kbd> opens the menu. See the install guide and the module list in the repository.
